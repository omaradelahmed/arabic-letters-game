# حروفي — لعبة الحروف والحركات

**اللعب مباشرة:** <https://omaradelahmed.github.io/arabic-letters-game/>

<img src="./qr/hurouf-qr.png" alt="كود QR للعبة حروفي" width="220" />

> امسح الكود بكاميرا الموبايل، أو افتح اللينك مباشرة.
> نسخة جاهزة للطباعة (بوستر A4 + 6 كروت للقص): [`qr/hurouf-qr-a4.pdf`](./qr/hurouf-qr-a4.pdf)

لعبة تعليمية مجانية في المتصفح للأطفال من **3 إلى 6 سنوات**.
الطفل يشوف حرفًا عليه حركة (مثل **رُ**)، والحرف يمشي لحد ما يوصله بابين،
كل باب فيه صورة وكلمة تبدأ بنفس الحرف — واحدة بنفس الحركة والتانية بفتحة أو كسرة.

- ✅ إجابة صح → علامة صح خضراء + نقطة + حرف جديد
- ❌ إجابة غلط → اللعبة تخلص (من غير أي إحباط أو مؤقت)
- 🔇 بدون موسيقى — مؤثرات صوتية قصيرة فقط
- 📴 تشتغل **بدون إنترنت** بعد أول فتح
- 📲 تتثبّت على التابلت/الموبايل (Add to Home Screen)
- 🔒 مفيش حسابات، مفيش إعلانات، مفيش تتبّع — كل حاجة على الجهاز

## الحروف والكلمات

| الحرف | مضمومة | مفتوحة | مكسورة |
|---|---|---|---|
| ر | رُطَب 🌴 | رَادْيُو 📻 | رِجْل 🦵 |
| س | سُكَّر 🍬 | سَيَّارَة 🚗 | سِنْجَاب 🐿️ |
| خ | خُبْز 🍞 | خَرُوف 🐑 | خِيَار 🥒 |
| ن | نُجُوم ⭐ | نَمْلَة 🐜 | نِمْر 🐆 |
| ت | تُفَّاح 🍎 | تَاج 👑 | تِمْسَاح 🐊 |
| ل | لُعْبَة 🧸 | لَيْمُون 🍋 | لِسَان 👅 |

> كل جولة: حرف + حركة، وبابين — واحد صح وواحد حركة تانية (فتحة أو كسرة).

## التشغيل محليًا

```bash
cd letters-game
python -m http.server 8000
```

بعدها افتح <http://localhost:8000>.

> لازم سيرفر (مش فتح `index.html` بالدبل كليك) عشان الـ Service Worker يشتغل والأوفلاين يشتغل.

## الأوفلاين والتثبيت

| المتصفح | التثبيت |
|---|---|
| Chrome / Edge (Android, Windows) | زر التثبيت في شريط العنوان، أو ⋮ → *Install app* |
| Safari (iPhone / iPad) | زر المشاركة → *Add to Home Screen* |

بعد أول فتح، كل الملفات تتخزن في الكاش (Service Worker) واللعبة تفتح بدون نت.

## ملاحظات تقنية

- **بدون أي مكتبات أو build step** — HTML/CSS/JS خام، حجم اللعبة أقل من 100KB.
- **الأصوات** مولّدة بـ WebAudio (oscillators) — مفيش ملفات صوت ولا موسيقى.
- **الكلام** عبر `speechSynthesis` بصوت عربي لو موجود على الجهاز؛ لو مش موجود الزر بيتخفي واللعبة تكمل عادي.
- **أفضل نتيجة** محفوظة في `localStorage` على الجهاز.
- **الوصول**: أزرار كبيرة، تباين عالي، `prefers-reduced-motion` محترم، واتجاه RTL.
- **الخصوصية**: مفيش أي طلبات شبكة بعد التحميل، ومفيش تحليلات.
